Diode Collab v1.22.14 was released on September 21st, 2026.

* Features:
  * Tunneled browser profile selection

## Tunneled browser profile selection

Each device now has a new "Local Setting" called "Tunneled Browser" on the profile page that allows the user to select which browser they want to use for E2EE browsing or VPN browsing.  In the past, this defaulted to the Brave Browser, but if the user didn't want to install Brave or if they had Brave installed to a unique location (e.g. Windows systems) then the tunneled browsing session could never launch.

With this release, Windows systems now attempt to auto-discover Brave, and all systems have an auto-discovery feature for supported Chromium browsers.   The user can select any of the Chromium browsers the app finds, or they can even enter in a custom path to a Chromium browser launcher if the auto-discovered options are not satisfactory.
