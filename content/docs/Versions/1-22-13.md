Diode Collab v1.22.13 was released on September 17th, 2026.

* Features:
  * Improve update download handling
* Bug fixes:
  * Windows installer improvements
  * Invites could fail due to a Base "eth\_call" error

## Improve update download handling

The auto-update feature has been improved to use smaller package zip files.

## Windows installer improvements

The Windows binary installer has been improved:

* Logs are rotated if files are locked
* The previous app instance is fully killed before installation
* Leftover installation files are removed

## Invites could fail due to a Base "eth\_call" error

Certain blockchain lookups fail if the device can't find the referenced element on chain.  These failures were not fully handled on the Base blockchain, causing a crash.  This was often experienced with Zone Invites, and could sometimes show an "Oops you found a bug" page or flash message when accepting invites.
