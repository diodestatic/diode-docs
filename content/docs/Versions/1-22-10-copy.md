Diode Collab v1.22.11 was released on September 9th, 2026.

* Bug fixes:
  * Windows disk space detector

## Heal private chats and DMs in Base-migrated Zones

Some of the Zones migrated from Moonbeam to Base still has private chat histories that were not accessible.  The edge cases that were in this state have been identified and fixed - all private chat histories should now be accessible.
